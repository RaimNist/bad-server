## Подготовка к работе
1. Склонировать репозиторий
2. Запустить docker
```bash
docker compose up -d
```
3. Наполнить базу данных
[README.md](.dump%2FREADME.md)
4. Перейти по адресу http://localhost:8081/ и на странице должны быть продукты.
5. На странице http://localhost:8081/login/ можно авторизоваться.
6. Админка находится по адресу http://localhost:8081/admin/
